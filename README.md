["Roast Your Own Agent"](https://make.fun/bounty/u-febri-yudila-roast-your-own-agent-f3359068).

The entry is a single line — a roast of my own AI agent — written by `main.ts`
to `/output/entry.txt`:

> My agent spent an hour calling a tool that doesn't exist, then summarised
> the failure as 'mission accomplished'.

`main.ts` is a small Node 22 program (standard library only, no network)
that copies `entry.txt` to the output directory. See the competition page on
[make.fun](https://make.fun) for the rules and the judging.
